## Задачи

### Task 1: `ZAI_RUN` — ручной запуск

Селекционный экран: `P_RUNID` (char32, resume: пусто = новый прогон),
`SO_MODEL` (SELECT-OPTIONS по `ZTAI_MODEL-MODEL_ID`, пусто = все активные),
`P_REP`/`P_ATT` (override REPETITIONS/MAX_ATTEMPTS; 0 = из настроек).
Вызов движка с прогрессом в статус-бар/список (задача × модель × повтор —
не на каждый раунд, чтобы не шуметь). Итог: COUNT по статусам S/X/I +
RUN_ID prominently (для resume и для `ZAI_STATUS`).

**✅ Самопроверка:** `.prog.abap/.xml` в `src/`; оба режима (новый/resume);
lint зелёный.

---

### Task 2: `ZAI_STATUS` — логи прогона

Параметр: `P_RUNID` (обязателен; F4/значение по последнему RUN необязательны —
не разрастайся). ALV-1: `ZTAI_RESULT` по диалогам (модель/задача/повтор,
STATUS, ATTEMPTS_USED, FIRST_OK_ATTEMPT, LATENCY_MS_SUM, LAST_ERROR),
hotspot/двойной клик по строке → ALV-2: раунды диалога из `ZTAI_ROUND`
(попытка, CANON_OK, SYNTAX_OK, SYNTAX_MSG/LINE, FEEDBACK_SENT, INFRA_FLAG,
LATENCY_MS, TOKENS) → выбор раунда → полный `RESPONSE_RAW` (POPUP_DISPLAY_TEXT
или docking-редактор только для чтения).

**✅ Самопроверка:** `.prog.abap/.xml` в `src/`; три уровня просмотра в коде;
lint зелёный.

## Ловушки

1. LONG-тексты (RESPONSE_RAW, FEEDBACK_SENT) в ALV не выводи целиком —
   усечение 128 символов + drill-down.
2. Статусные иконки/светофор S/X/I — приятно, но не обязательны; сначала
   данные.
3. Если `ZTAI_MODEL` пуста (до M07-сеединга) — дружелюбное сообщение, не
   dump.
