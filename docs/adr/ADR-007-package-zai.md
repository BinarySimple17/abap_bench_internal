# ADR-007: Пакет объектов — транспортный `ZAI`

- **Статус:** Принято (2026-10-14)
- **Дата:** 2026-10-14
- **Контекст принятия:** решение владельца при планировании батча фазы 1 (закрывает открытый вопрос PLAN.md §13.1)
- **Связанные документы:** `PLAN.md` §10/§13 (синхронно правится), ADR-004 (неймспейс `Z*AI_*`), ADR-006 (фаза 1, деплой M07)

---

## 1. Контекст

Все объекты бенчмарка (`Z*AI_*`, ADR-004) должны создаваться в dev-системе в
одном пакете. До сих пор вопрос «транспортный `ZAI` vs `$TMP`» был открыт
(PLAN.md §13.1) и висел предусловием сессии M01. abapGit-контракт репозитория
работает с обоими вариантами, поэтому выбор — про эксплуатацию, не про
инструменты.

## 2. Решение

**Транспортный пакет `ZAI`.** Объекты создаются в пакете `ZAI` с записью в
транспортные запросы (один рабочий TR на батч изменений фазы 1). Обоснование:
объекты переживают чистки персональных объектов dev и пересоздание
пользователя; появляется стандартный путь переноса в другие системы через
CTS при сохранении abapGit-синхронизации как основного канала с git.

Отдельно: пакет для установки aisdkforsapabap (BL-1, фаза 2) — **не** `ZAI`,
чужой код живёт в собственном пакете (ADR-005).

Синхронные правки: `PLAN.md` §10 (строка «Пакет»), §13.1 (закрыто),
сессии M01/M07 (пакет — предусловие/шаг деплоя).

Последствия: положительные — сохранность и переносимость; отрицательные —
каждая активация требует TR (небольшая рутина на M07). Критерий пересмотра:
если транспортная логика системы станет недоступна, откат на `$TMP` —
apt-правка этого ADR без изменений в коде.

## 3. Сравнение по осям решения

| Ось | Транспортный `ZAI` (принято) | `$TMP` |
|---|---|---|
| Переживает чистки dev / пересоздание пользователя | да | нет |
| Перенос в другие системы | CTS штатно | только abapGit-выгрузка |
| Рутина при активации | нужен TR | не нужен |

**Итог сверки:** решающая ось — сохранность объектов; рутина TR пренебрежима.

## 4. Рассмотренные варианты

### Вариант A — `$TMP`
Отвергнут: объекты привязаны к пользователю и не переживают пересоздание;
перенос только вручную.

### Вариант B — транспортный `ZAI` ✅ **ПРИНЯТО**
Основание: §2.
