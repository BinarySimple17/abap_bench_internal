# BL-1: Установить Microsoft AI SDK for ABAP в dev-систему

- **Тип:** задача
- **Приоритет:** P1 (блокирует smoke с реальным LLM на M2; M1 идёт без него)
- **Состояние:** новый
- **Владелец:** M
- **Источник (трассировка):** [ADR-005](../../docs/adr/ADR-005-llm-sdk.md) — SDK выбран как общий случай
- **Зависимости:** — (идёт параллельно с M01)

## Что сделать

Установить [microsoft/aisdkforsapabap](https://github.com/microsoft/aisdkforsapabap)
в dev-систему через abapGit: выбрать отдельный транспортный пакет под SDK (не
наш `ZAI`), перед установкой проверить пересечения имён с нашими объектами
(`Z*AI_*` — PLAN.md §10), установить, активировать все объекты, прогнать
пример из документации (<https://microsoft.github.io/aisdkforsapabap>).
Зафиксировать фактическую версию (tag/commit) — на неё опирается прокси
`ZCL_AI_LLM_SDK_PROXY`.

## Критерий закрытия

Пример из документации SDK возвращает ответ модели в системе; версия SDK
зафиксирована в этом элементе или в отчёте сессии.

## Контекст и альтернативы

SDK чужой (Z-неймспейс, активная разработка) — ставится отдельно от наших
объектов и не синхронизируется в репозиторий бенчмарка. Альтернатива
(собственный SDK) отвергнута — ADR-005.
